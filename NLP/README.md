# Документация модуля NLP-аналитики «Reputation Meter»

## 1. Назначение модуля
Данный инструмент является ключевым компонентом MVP сервиса **Reputation Meter**. Он реализует автоматизированный процесс обработки неструктурированных отзывов клиентов, превращая текст в понятные бизнес-метрики.

**Основные функции:**
* **Сентимент-анализ (F-02):** Автоматическое определение эмоционального окраса (Позитивный, Негативный, Нейтральный).
* **Тематическая классификация (F-03):** Распределение отзывов по 5 категориям: *Обслуживание, Качество еды, Чистота, Интерьер, Цена*.
* **Визуализация данных:** Построение дашбордов для выявления «болей» бизнеса.

## 2. Архитектура решения
Система построена на принципе пакетной обработки данных (Batch Processing), что обеспечивает стабильность при больших объемах входной информации.



**Этапы обработки:**
1. **Sanitization:** Очистка исходного CSV от «битых» символов и лишних переносов строк.
2. **Preprocessing:** Токенизация текста и ограничение длины (max 512 токенов) для оптимизации памяти.
3. **Inference:** Анализ текстов с использованием глубоких нейросетей семейства **ruBERT**.
4. **Formatting:** Конвертация ответов моделей в человекочитаемый вид и расчет уверенности (`confidence`).

## 3. Технологический стек
* **Нейросети:** * `blanchefort/rubert-base-cased-sentiment` (Тональность).
    * `cointegrated/rubert-base-cased-nli-twoway` (Тематики).
* **Среда:** Python 3.10+, PyTorch (GPU T4), Hugging Face Transformers.
* **Аналитика:** Pandas, Seaborn, Matplotlib.

## 4. Инструкция по использованию в Google Colab
1. Включите GPU (**Edit -> Notebook settings -> T4 GPU**).
2. Загрузите файл `example.csv` в корневую папку (значок папки слева).
3. Запустите ячейку с кодом.
4. По завершении в папке появятся:
    * `final_reputation_report.csv` — структурированная база данных.
    * `reputation_dashboard.png` — графический отчет для презентации.

## 5. Соответствие бизнес-требованиям (BRD)
Разработанный модуль полностью закрывает потребности следующих архетипов:
* **Инвестор (Архетип 3):** Получает наглядный график динамики репутации.
* **Владелец бизнеса (Архетип 4):** Видит распределение проблемных зон без необходимости вникать в код.
* **Технический директор (Архетип 5):** Имеет структурированный CSV для интеграции в CRM через API.
